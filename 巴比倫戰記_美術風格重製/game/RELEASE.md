## 建置與預覽

需要 Node.js，正式打包不需安裝第三方依賴：

```text
node tools/build-release.cjs
node tools/serve.cjs
```

本機預覽：`http://127.0.0.1:4178/`。
部署檔預覽：`http://127.0.0.1:4178/dist/index.html`。
本機美術檢查：`http://127.0.0.1:4178/?review=1`，工具列僅對 localhost 開放。
`build-assets.cjs` 是素材製作工具，使用本機 Sharp；已有完整圖檔時不需執行。

## 部署

目標既有網站： https://endearing-salamander-fc944d.netlify.app/

2026-10-03 驗收時，Netlify 團隊頁顯示 production deploys paused，剩餘 operational credits 不能用於正式部署。因此本次沒有覆蓋線上站，網址仍是舊版。必須先由帳戶恢復部署額度／下個計費週期恢復後，才能發布。

恢復後將 `dist` 內容或本次的部署 ZIP 上傳到既有專案即可。若使用 Git 建置，`netlify.toml` 已指定建置命令與 `dist` 輸出。不要上傳整個素材工作資料夾。

`dist/release-manifest.json` 列有檔案大小與 SHA-256。相同原網址上的存檔鍵維持不變；不同網域或本機預覽不會自動共用存檔。
