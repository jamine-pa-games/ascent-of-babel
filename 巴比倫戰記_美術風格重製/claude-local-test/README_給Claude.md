# 巴比倫戰記：美術套用版本地測試包

此包包含可直接執行的 HTML、CSS、JavaScript、115 張美術素材與本地 Three.js。無需 npm install 或重新生成圖片。程式與 2026-10-03 部署包相同，本次僅附加測試說明與啟動工具。

## 啟動

解壓後，在含 index.html 的資料夾執行：

```sh
node serve.cjs
```

開啟 http://127.0.0.1:4179/ 。如 4179 被占用，可執行 `node serve.cjs 4180`，改開 http://127.0.0.1:4180/ 。

也可使用任何靜態 HTTP 伺服器服務此資料夾。不要只抽出 index.html；art/ 和 vendor/ 必須一起保留。Google Fonts 使用外部連線，離線時會採用系統字型。

## 請 Claude 執行的工作

先在本地啟動並驗證，不要部署 Netlify。

1. 檢查圖片、腳本載入及瀏覽器錯誤。
2. 用 390×844 和 360×800 手機尺寸測試開場、守望者問答、三人編隊、世界地圖、出擊、移動、技能與回合交替。
3. 測試重新整理後的「繼續旅程」。存檔存在目前 origin 的 localStorage，本地和線上存檔各自獨立。
4. 使用 `http://127.0.0.1:4179/?review=1` 的本機美術檢查工具切換六章、觸發六屬性效果。這是測試入口，不代表正常流程已解鎖所有關卡。建議使用独立測試瀏覽器環境，避免與其他同 origin 的存檔混用。
5. 回報實際錯誤、版面遮擋、人物比例與風格一致性問題，附實機截圖。不要將未通關的內容標為已驗證。

## 檔案

- index.html：原遊戲邏輯與頁面。
- manuscript.css / manuscript.js：美術與手機版修正、動作特效。
- art/：115 張新版圖片。
- vendor/three.min.js：本地繪圖函式庫。
- _headers：Netlify 快取規則。
- release-manifest.json：部署檔雜湊清單，範圍不含本次附加的 README 與 serve.cjs。

此包根目錄的 index.html 及其相依檔案即為靜態網站輸出，可交給 Netlify 手動部署。README 與 serve.cjs 僅供本地測試，不是網站執行所需。既有網址未更新，先前 Netlify 因額度而暫停正式部署，請重新確認帳戶狀態。
