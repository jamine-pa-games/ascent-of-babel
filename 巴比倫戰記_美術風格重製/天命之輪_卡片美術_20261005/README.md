# 天命之輪｜24 張卡片美術

本包為卡片美術與排版模板，不是已上線的輪盤系統。角色沿用已完成的立繪，沒有重新生成角色臉孔或肢體。

- 星宿 12 張：古金與青金石卡框。
- 邪獸 11 張＋金古：朱銅卡框。
- 共用卡背 1 張：青金石、八芒星與天命輪盤紋飾。
- 卡面 768×1152（2:3），另附 384×576 WebP，適合手機介面。
- 卡面只有名稱、屬性、系列及圖鑑順序；未擅自新增攻防數值、稀有度或卡片技能。
- 名稱與屬性由程式排版；角色圖與生成的卡框是可獨立重用的素材。
- 金古的屬性未在附件的星宿／邪獸屬性表中明列，因此暫不標示，僅標上「命運之板持有者」，待最新版程式確認後補齊。

`cards_png/` 為高解析卡面；`cards_webp/` 為遊戲用版本；`templates/` 含空白卡框與卡背；`手機預覽/` 為直式六張卡總覽。

手機輕量包僅含 `cards_webp/`、`手機預覽/` 及說明／對照表，不含高解析 PNG 與空白模板。使用輕量包時，請讀取 cards.json 的 `webp` 欄位；`png` 欄位對應的是完整高解析包。

`cards.json` 對照原角色 key、名稱與屬性。卡面檔名以 `card_` 加上原角色 key，例如 `card_star_hired.webp`，不要拿卡面去覆蓋戰鬥立繪 `star_hired.webp`。

卡框與卡背使用內建圖像生成工具，提示詞收錄於 `生成提示詞.json`。文字、卡面合成與尺寸輸出是可重現的 UI 排版流程。

目前沒有更動遊戲程式、抽取機率、存檔、輪盤互動或線上部署。取得含天命之輪的最新版遊戲程式後，才可接入收藏介面、獲得卡片畫面與嵌卡動畫並驗證。
