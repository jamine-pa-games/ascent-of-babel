# 巴比倫戰記｜美術風格重製

本資料夾是「古巴比倫 × 中世紀彩飾手抄本」版本的完整美術方向包。

## 交付內容

- `巴比倫戰記_美術風格聖經.md`：完整的畫面、戰鬥、角色、場景、特效、動畫、UI 與交付規則。
- `01_世界地圖_風格基準.png`：世界地圖、路線、節點與地標基準。
- `02_岩獄戰鬥_風格基準.png`：斜俯視格子戰鬥、角色比例、地形高低差與頭目尺度基準。
- `03_六屬性特效_風格基準.png`：地、水、火、風、光、闇的形狀、材質與發光規則。
- `04_動畫關鍵幀_風格基準.png`：果凍旅人、戰士、葛隆與世界地圖地標的動作節奏。
- `05_角色魔物召喚獸_風格基準.png`：吉祥物、人類、普通魔物、邪化天王與淨化召喚獸的比例及材質。
- `圖像生成提示詞.md`：本次基準圖的完整提示詞，可作為後續批次重製的母版。
- `原始素材/`：使用者提供的素材副本，保留供比對，不代表最終風格。

## 一句話方向

以古巴比倫的泥板、楔形文字、青金石、氧化銅和階梯神塔為骨架，加入中世紀彩飾手抄本與波斯細密畫的線條、金箔和礦物顏料，形成可讀性優先、莊嚴而有手工溫度的日式戰略 RPG。
