# 深度學習：通天之塔 / Deep Learning: Ascent of Babel

本分支 `art-revamp-202610` 收錄《通天之塔》v23.1（2026-09-28）。本次修正以新的提交取代先前誤放的《巴比倫戰記》檔案；main 不變，既有提交歷史保留。

## 遊戲入口

- `index.html`：由最新版來源重新打包的完整單檔 HTML，可直接以瀏覽器開啟，內嵌美術與字型，保留原圖畫質。
- `web/index.html`：可維護的網站版入口，搭配同目錄模組、字型、翻譯及美術資源。

## 檔案內容

- `web/`：732 個檔案，完整 v23.1 遊戲、角色與怪物美術、場景、動畫、字型、音樂程式及既有測試。
- `art_raw/`：258 個原始美術與製作參考檔案，包含 hd-v18、角色、頭目、地形、聚落、旅程地圖、序章、宣傳圖等。
- `docs/`：34 份遊戲設計、美術規格、提示詞、版本與發布紀錄。
- `tools/`：52 個建置、美術處理與驗證工具。
- `godot/`：54 個 Godot 專案與實驗檔案。
- `UPLOAD-MANIFEST.tsv`：遊戲及來源檔案的相對路徑、大小與 SHA-256 清單；不列入本說明、忽略規則與清單本身。

## 來源與驗證

遊戲及開發來源為本機發布工作目錄 `yubao-tts-rpg-v22-release` 的提交 `d3a5b38fcf581b614773fbe12343d973c43cb436`。該目錄名稱沿用 v22，提交內容已是 v23.1。原始美術補齊自 `yubao-tts-roguelike-publish/art_raw`；重疊檔案完全一致。

已逐檔核對全部 1,130 個來源檔案。新增根目錄單檔由原工具 `python tools/build_single.py index.html --full` 產生，沒有修改遊戲程式。

驗證包含賢者 5 項、塔外探索 6 項、存檔 17 項；另以實際 Chromium 載入單檔的封面、聚落及通天塔，確認 18 章、6 種調合配方、美術無載入失敗、無 JavaScript 錯誤且無外部 HTTP 請求。瀏覽器測試為桌面 Chromium 的手機尺寸模擬。
